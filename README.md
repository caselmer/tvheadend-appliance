# TVHeadend Appliance

> Eine reproduzierbare TVHeadend-Installation für Debian 12 unter Proxmox LXC.

## Ziel

Dieses Projekt erstellt eine stabile TVHeadend-Umgebung für IPTV.

Funktionen:

- TVHeadend aus dem offiziellen Repository
- IPTV (M3U)
- XMLTV
- automatische Aktualisierung
- systemd-Timer
- wartungsarm

## Voraussetzungen

- Proxmox VE
- Debian 12 LXC
- Internetzugang
